## Lancer le code

Prérequis : Python supérieur à 3.10.

```bash
git clone https://github.com/yanterret/surrogate-poutre.git
cd surrogate-poutre
pip install -r documentation/requirement.txt
python surrogate_poutre/surrogate_pipeline.py
```

Les résultats sont écrits au format CSV dans `surrogate_poutre/resultats/`.
